Create a Python function `add(a, b)` that calculates the sum of two financial figures, `a` and `b`, representing expenses. Demonstrate its usage by adding two sample expenses: `add(200.50, 150.75)`, and print the result as a formatted currency string.

============ USER ============
Instruction: Create a Python function `add(a, b)` that calculates the sum of two financial figures, `a` and `b`.
Input: None

========== ASSISTANT ==========
Solution:
```python
def add(a, b):
    return a + b
```

============ USER ============
Instruction: Demonstrate the usage of the `add` function by adding two sample expenses: `add(200.50, 150.75)`, and print the result as a formatted currency string.
Input: None

========== ASSISTANT ==========
Solution:
```python
def add(a, b):
    return a + b

result = add(200.50, 150.75)
formatted_result = "${:,.2f}".format(result)
print(formatted_result)
```
